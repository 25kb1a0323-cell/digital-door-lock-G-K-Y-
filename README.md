# Digital Door Lock System

An Arduino-based digital door lock security system featuring custom passcode entry and visual feedback, designed and simulated using **Wokwi**.

## 📌 Project Overview
Simulates keyless access control by integrating keypad/passcode inputs with output indicators (LEDs, relays, actuators) to grant or deny entry.

## 📁 Repository Files
* `sketch.ino` - Core Arduino logic and passcode validation.
* `diagram.json` - Wokwi circuit schematic.
* `libraries.txt` - Required Arduino dependencies.
* `digital door lock [G,K,Y].png` - Circuit layout diagram.

## 🛠️ Components (Simulated)
* **Microcontroller:** Arduino Uno / ESP32
* **Input:** Keypad / Push Buttons
* **Output:** LCD/OLED Display, LEDs, Servo Motor/Solenoid, Buzzer

## 🚀 How to Run
1. Open [Wokwi Simulator](https://wokwi.com/).
2. Load `sketch.ino`, `diagram.json`, and `libraries.txt` to run the interactive simulation.
